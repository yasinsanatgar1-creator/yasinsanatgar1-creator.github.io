# Russia: A Land of Endless Horizons

A small, static travel and culture website about Russia.

## Project files

- `index.html` — the complete responsive website and its styles.
- `robots.txt` — allows search crawlers and points them to the sitemap.
- `sitemap.xml` — lists the public homepage for search engines.

There is no build step. Open `index.html` in a browser to preview the site. The live version is published with GitHub Pages.
